Why is this needed?
GitHub Pages hosts the app, not your personal uploads. Supabase Storage stores your files and creates public share links. Create a public bucket named qr-uploads in your Supabase project.
🔐 Only use your Supabase anon/publishable key here. Never put a service-role or secret key in a website. For public sharing, uploaded files are accessible to anyone with the link. Configure bucket policies and file limits in Supabase.
